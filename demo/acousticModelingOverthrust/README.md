
3D acoustic modeling in the SEG/EAGE Overthrust model
* P-wave velocity (m/s) binary input file `fvp`
* grid size 187 x 801 x 801
* orientation z, x, y
* spacing 25m in all dir

To run the demo
* 2D modeling with `sh run2DmodelingOverthrust.sh`
* 3D modeling with `sh run3DmodelingOverthrust.sh`

Computed seismic traces are displayed with SU (Seismic Unix)
